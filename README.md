Collection of LAMMPS data files for the defected MoS2 structures investigated in the paper "Superlattice Thermal Modulation in MoS2 by Defect Engineering"

The data files names contain different strings:
- Lx{100,..,2000}a_0 refers to the length of the system along the x direction in lattice constant units
- 0.01, 0.025, 0.05, 0.1 refers to the vacancy density as defined in the manuscript
- Defects/Ordered-defects refers to the distribution of vacancies (random vs ordered strips)
- {1,..,8}col refers to the number of vacancy strips in the ordered samples

Cite the paper as

R. Dettori, F. Siddi, L. Colombo, C. Melis, 
"Superlattice Thermal Modulation in MoS2 by Defect Engineering"
Adv. Theory Simul. 2025, 8, 2401199.
